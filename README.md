# HabitTracker

A simple Android habit tracking application built with Kotlin and Jetpack Compose.

HabitTracker helps you build and track daily habits, monitor progress, and keep consistency with your goals.

## Download

Latest version:

[Download APK](../../releases/latest)

## Features

- ✅ Create and manage habits
- ✅ Track daily completion
- ✅ Weekly calendar view
- ✅ Habit statistics
- ✅ Time tracking for habits
- ✅ Local data storage
- ✅ Material 3 UI

## Technologies

The project is built with:

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Room Database**
- **Kotlin Coroutines**
- **StateFlow**
- **Android Architecture Components**

## Architecture

The application uses a layered architecture:

```
UI (Jetpack Compose)
        |
    ViewModel
        |
   Repository
        |
    Room Database
        |
     SQLite
```

## Requirements

- Android 8.0 (API 26) or higher

## Installation

1. Download the latest APK from Releases.
2. Enable installation from unknown sources.
3. Install the application.
