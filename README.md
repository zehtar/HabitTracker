# HabitTracker

A simple Android habit tracking application built with Kotlin and Jetpack Compose.

HabitTracker helps you build and track daily habits, monitor your progress, and maintain consistency with your goals.

## Download

Get the latest stable version:

[Download APK](../../releases/latest)

## Features

* ✅ Create, edit, and delete habits
* ✅ Track daily habit completion
* ✅ Weekly calendar with date selection
* ✅ Completion statistics
* ✅ Track time spent on habits
* ✅ Local data storage
* ✅ Home screen widget
* ✅ Open individual habits directly from the widget
* ✅ Automatic widget updates
* ✅ Material 3 UI

* **StateFlow**

## Architecture

The application uses a layered architecture:

```text
UI (Jetpack Compose)
        |
    ViewModel
        |
   Repository
        |
    Room Database
        |
     SQLite
```

## Requirements

* Android 8.0 (API 26) or higher
